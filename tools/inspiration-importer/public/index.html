Conectar o actualizar WordPress

Descargar complemento 0.2.0 con la categoría Cat eye. En WordPress, ve a Plugins → Añadir nuevo → Subir plugin. Si ya está instalado, elige reemplazar la versión actual.

Para la primera conexión, configura la contraseña de aplicación en el archivo local indicado en el README y reinicia el servidor.
